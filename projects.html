Hosting a static HTTPS website using AWS services

What the project is about:

    The objective of this project is to implement a highly available static website hosting solution using AWS.
    Required AWS services include:
  • S3 Buckets to host website pages
  • Route 53 to link the domain name to the website
  • AWS Certificate Manager (ACM) to create an SSL certificate
  • CloudFront distributions to secure the website in HTTPS
Note: The approx. annual budget of this project is less than $20.
